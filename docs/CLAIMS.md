## Replay: every displayed numeric field

[`scripts/readme-claims.test.ts`](../scripts/readme-claims.test.ts) reads the committed report and checks every cell in the marked README table, the facts block, row membership/count/order, and absence of additional numeric prose in the results section. Changes to README numbers or report values fail `npm test` until they agree. The keeper replay regression separately recomputes the report from fixtures (`packages/domain/src/replay.test.ts`). This does not bless a manually falsified report.
