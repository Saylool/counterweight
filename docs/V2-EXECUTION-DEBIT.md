# Historical v2 execution-debit model

This calculation applies to v2 and does not bound v3 exit losses. V3 exit marks are unauthenticated; a false mark can cost up to the perp margin, while wNEAR custody is unaffected.

For v2, keeper maximum direct execution debit: let K = floor(5,000 / 5) = 1,000 lifetime keeper/public authorizations, Q = max(reserved short, max_short_size), and L = tick-rounded-up(max_price × (1 + price_band_bps / 10,000)). Then **D ≤ K × ceil_micro(Q × L × (1 + f))**, assuming taker fee f = 0.00045. The historical cancellation fixture used Q = 1 NEAR and L = $1.0605, giving $1,060.978 (`configured_keeper_maximum_direct_execution_debit_bound`). The [funded v2 plan](FUNDED-LIFECYCLE.md) uses Q = 5 NEAR and live mark bounds, so that historical dollar ceiling does not apply; for the $3.6348 test mark the funded ceiling is $22,036.913 including tick and per-action micro rounding (`scripts/testnet.test.ts`). This counts the entire buy debit, including principal, even if every authorization is a filled close; cancellations consume the same allowance. Bound assumes fixed limits and no owner budget replenishment. Subsidized MPC fees separately cost at most **10 NEAR** over that allowance (1,000 × 0.01 NEAR); gas paid by callers is separate. There is **no finite total portfolio-loss guarantee**: market moves, funding, liquidation, venue/oracle failure, missed hedges and owner attestations are outside this execution-debit bound. The fee is a model assumption, not enforced venue pricing. A daily churn formula based only on the open cap omits uncapped recovery turnover.
